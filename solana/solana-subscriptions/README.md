# Index every plan, subscription and pull on Solana's Subscriptions program

This is a HyperIndex indexer, so it now lives in its own repo with the rest of the HyperIndex examples.

**[enviodev/hyperindex-use-cases/tree/main/solana-subscriptions](https://github.com/enviodev/hyperindex-use-cases/tree/main/solana-subscriptions)**
