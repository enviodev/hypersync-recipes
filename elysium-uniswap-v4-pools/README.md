# Index every Uniswap v4 pool on Elysium over RPC

This is a HyperIndex indexer, so it now lives in its own repo with the rest of the HyperIndex examples.

**[enviodev/elysium-uniswap-v4-indexer](https://github.com/enviodev/elysium-uniswap-v4-indexer)**

It keeps the data up to date as new blocks arrive and serves it over GraphQL. If you only need an answer or a one-off pull, the HyperSync scripts in the [main README](https://github.com/enviodev/hypersync-use-cases#readme) are quicker. All the HyperIndex examples are listed in [hyperindex-use-cases](https://github.com/enviodev/hyperindex-use-cases).
